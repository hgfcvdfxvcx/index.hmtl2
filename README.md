# 🎁 Case Clicker

Ett enkelt och snyggt **Case Clicker-spel** gjort med HTML, CSS och JavaScript.

Klicka för att tjäna coins, köp upgrades, öppna cases och samla sällsynta items! ⭐

## 🎮 Funktioner

* 💰 Klicka för att tjäna coins
* ⚡ Uppgradera coins per klick
* 🤖 Köp Auto Clickers
* 📦 Öppna olika cases
* 🎡 Spinna och få slumpmässiga items
* 🎒 Inventory-system
* ⭐ Olika rarities:

  * Common
  * Uncommon
  * Rare
  * Epic
  * Legendary
* ✨ Animationer
* 💾 Automatisk sparning med `localStorage`
* 📱 Fungerar på dator, Chromebook och mobil

## 🏆 Items

Spelet innehåller fiktiva items med olika rarities och värden.

| Rarity       | Exempel        |
| ------------ | -------------- |
| ⚪ Common     | Blue Pixel     |
| 🟢 Uncommon  | Silver Star    |
| 🔵 Rare      | Neon Orb       |
| 🟣 Epic      | Galaxy Crystal |
| 🟡 Legendary | Golden Crown   |

## 💰 Coins

Coins tjänas genom att klicka på myntet.

Du kan sedan använda dina coins för att:

* Köpa starkare klick
* Köpa Auto Clickers
* Öppna cases
* Använda Spin

**Spelet använder endast virtuell spelvaluta och riktiga pengar används inte.**

## 📦 Cases

### Basic Case

**100 coins**

En vanlig case med främst Common och Uncommon items.

### Premium Case

**500 coins**

Bättre chans på Rare, Epic och Legendary items.

### Legend Case

**2 000 coins**

Högre chans på de mer sällsynta itemsen.

## 🎡 Spin

Spin kostar **250 coins** och ger ett slumpmässigt item.
